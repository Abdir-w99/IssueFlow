# IssueFlow

IssueFlow is a simple web application where users can add, view, update, and delete issues. It is built with HTML, CSS, and JavaScript and is designed as a tool for organizing and tracking issues and tasks.

## Features

- Add new issues
- Delete issues
- Change issue status between **Open** and **Closed**
- Validate empty form fields
- Save issues in **localStorage**
- Load saved issues automatically when the page reloads

## Built With

- HTML
- CSS
- JavaScript

## How to Run the Project

1. Clone or download the repository
2. Open the project folder
3. Open `index.html` in your browser

## Purpose of the Project

The purpose of this project was to practice JavaScript concepts and build a simple tool for organizing and tracking issues and tasks.
